#  Cartix iOS
This will be the official Cartix iOS application.

## Objectives
The main objective of this application is to provide a service for users to make organized shopping lists before going to the supermarket.
By using barcode scanning, storing product data on the cloud and providing crowdsourcing abilities to this app, users can help other users get a prespective on how much they are spending.

## Development
I want to make this application as professional as I can make it on my own without sacrificing user experience.
